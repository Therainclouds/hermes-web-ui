Upstream 0.6.39→0.6.42 sync merged `observeChatRunWebhookEvent` into the
chat-run socket:

- `emitExternalEvent` and `emitToSession` now resolve the run profile
  (`resolvePetEventProfile`) and publish `ChatRunWebhookEvent` records to the
  chat-webhooks dispatcher (Chat Run lifecycle webhooks, upstream #2452).
- Events broadcast to the session namespace now pass through
  `buildOutboundRunEvent` (`emitExternalEvent`) so terminal payloads are shaped
  consistently with the resume path.
- The local Petdex pet feature stays removed (local 52f35890 decision); pet
  state observation (`observeRunChatPetEvent`) is not merged back.
- `emitExternalEvent` now also forwards to `args.onEvent` when the bridge emit
  closure is used, matching upstream's single-caller contract.
