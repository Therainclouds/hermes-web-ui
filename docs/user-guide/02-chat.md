# 2. AI 对话

**路由**：`/hermes/chat`（或带 sessionId 的会话详情）

> [← 返回索引](./README.md)

## 主界面分区

| 区域 | 说明 |
| --- | --- |
| 左侧会话列表 | 所有本地会话，按来源（Telegram/Discord/Slack 等）分组折叠 |
| 中间消息流 | Markdown 渲染、代码高亮、工具调用折叠 |
| 底部输入框 | 多行输入、文件拖拽、语音输入、Slash 命令 |

## 关键操作

- **新建会话**：点左下角「+」按钮 → 自动选默认 profile/模型。
- **切换模型**：输入框上方下拉；不同 profile 下能看到的模型不同（取决于当前 profile 已配置的提供商与凭证）。
- **上传文件**：拖拽文件到聊天区，或点输入框旁的回形针图标。上传后的文件绑定到当前 profile 的上传目录。
- **下载文件**：点击消息中由 Agent 生成的「文件链接」，支持本地 / Docker / SSH / Singularity 后端按路径下载。
- **工具调用详情**：每条 Agent 回复下方的「工具调用」可展开参数和返回结果。
- **中断运行**：回复生成中可点「停止」按钮。
- **会话搜索**：按 `Ctrl + K` 唤起搜索框，只搜本地 Web UI 会话库（Hermes 原生历史库只读）。
- **侧边操作**：右键会话列表项 → 重命名 / 删除 / 切换 profile。

## 顶部标签页标题

打开某个具体会话时，浏览器标签页标题会自动切换为该会话的标题，便于多任务切换。
