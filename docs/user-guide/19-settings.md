# 19. 设置

**路由**：`/hermes/settings`（多 Tab，通过 URL `?tab=xxx` 切换）

> [← 返回索引](./README.md)

## Tab 清单

| Tab | 说明 |
| --- | --- |
| `account` | 当前账户改名 / 改密码 / 移除密码登录 |
| `users` | **仅超级管理员**：用户管理（增删、改角色、绑 profile、启用/禁用） |
| `display` | 流式输出、紧凑模式、是否展示推理、是否展示成本 |
| `agent` | 最大回合数、超时、强制工具调用策略 |
| `gateway` | 网关自启动策略 |
| `memory` | 记忆开关、字符上限 |
| `compression` | 长上下文自动压缩阈值、压缩模型 |
| `session` | 会话空闲超时、定时重置 |
| `privacy` | PII 脱敏规则 |
| `models` | 默认模型 + 默认提供商 |
| `voice` | TTS / STT 提供商、声音、克隆参考音频 |
