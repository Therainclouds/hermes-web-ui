# 8. 配置（Profile）

**路由**：`/hermes/profiles`  
**权限**：**仅超级管理员**

> [← 返回索引](./README.md)

Hermes 的「工作环境」概念。每个 profile 是独立的配置 + 缓存 + 上传 + 会话 + 任务等容器。

## 可执行操作

| 操作 | 步骤 |
| --- | --- |
| **新建** | 右上角「创建」→ 输入名称 → 创建 |
| **重命名** | 行内菜单「重命名」 |
| **克隆** | 行内菜单「克隆」→ 输入新名字（继承所有配置与缓存） |
| **删除** | 行内菜单「删除」→ 二次确认 |
| **导入** | 右上角「导入」→ 选择压缩包文件（来自其他部署或备份） |
| **导出** | 行内菜单「导出」→ 下载压缩包文件用于迁移/备份 |
| **切换** | 点击左侧 profile 名（顶部 sidebar 的头像区也可切换） |

## 重要约束

- 切换 profile 后，会话、模型、上传、看板、任务全部切换到对应 profile。
- **普通管理员**只能看到与自己账户绑定的 profile；**超级管理员**可见全部。
