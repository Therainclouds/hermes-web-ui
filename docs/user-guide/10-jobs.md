# 10. 定时任务

**路由**：`/hermes/jobs`

> [← 返回索引](./README.md)

Cron 表达式驱动的自动化任务（绑定到当前 profile）。

## 操作流程

1. 右上角「新建任务」→ 填写：
   - 名称、描述
   - Cron 表达式（提供「每小时 / 每天 / 每周」等快捷预设）
   - 触发时要发送给 Agent 的提示词
2. **列表视图**：每个任务卡片展示状态、上下次执行时间。
3. **立即执行**：点「▶ 运行」可手动触发，不等 Cron。
4. **暂停 / 恢复**：行内切换按钮。
5. **编辑 / 删除**：行内操作。
6. **运行历史**：下方面板展示每次执行的开始时间、耗时、结果摘要。
7. **排序**：顶部可按名称 / 时间排序。
