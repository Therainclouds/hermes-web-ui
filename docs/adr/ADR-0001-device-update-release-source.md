# ADR-0001：设备更新的事实源与分发源

- 状态：accepted
- 日期：2026-06-07

## 背景

当前设备端更新检测依赖 npm registry，而 `source-deploy` 的实际下载依赖 GitHub tag archive。事实源分裂导致：

- 检测与执行可能不一致
- GitHub archive 稳定性不足
- 后续难以挂载摘要校验与回滚元数据

## 决策

- 设备端更新引入独立的 manifest 作为更新元数据中心。
- 设备真正下载的更新物改为自有下载源上的 `device-package`。
- 第一阶段允许保留 npm 作为版本发现兼容链路。
- 中长期目标是检测与执行都基于 manifest。

## 后果

正向影响：

- 更新检测与下载执行可逐步收敛到单一事实源。
- 自有源可附带摘要、兼容性、回滚信息。
- 更新地址更稳定、可镜像、可缓存。

代价：

- 需要新增清单解析、发布工作流与下载源结构。
- 在双轨期内仍需处理 npm 与 manifest 可能短暂不一致的问题。
