# ADR-0002：设备更新权限模型

- 状态：accepted
- 日期：2026-06-07

## 背景

设备是买断制产品，用户需要像消费电子设备一样自行决定是否升级版本。但设备更新会改写部署目录并重启 `systemd`，客观上需要高权限执行。

## 决策

- 登录用户可触发升级到当前官方稳定版。
- Web UI 主服务继续以普通用户运行。
- 安装、替换文件、重启服务等高权限动作收敛到 privileged installer。
- 不采用整个项目默认 `root` 常驻运行的方案。
- 高风险操作暂不开放给普通用户：换源、切通道、降级、手动回滚、关闭校验。

## 后果

正向影响：

- 符合设备产品的自助更新体验。
- 避免把 Web UI 的所有漏洞都放大为整机 root 风险。
- 后续更容易对高风险操作做单独控制。

代价：

- 需要维护受控提权链路，例如 `sudoers` 或 root helper。
- 权限模型实现比全程 root更复杂，但更安全且更可维护。
