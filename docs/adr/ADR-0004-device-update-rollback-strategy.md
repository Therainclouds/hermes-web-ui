# ADR-0004：失败自动回退与未来手动回滚策略

- 状态：accepted
- 日期：2026-06-07

## 背景

设备端更新链路一旦失败，不应把设备留在半更新或不可启动状态。同时本轮目标要求为未来手动回滚预留空间，但不应在第一阶段引入过重的复杂度。

## 决策

- MVP 先实现失败自动回退。
- 每次安装前创建 last-known-good 备份。
- 当下载、校验、安装、重启或健康检查失败时，自动恢复备份。
- 手动回滚、指定版本降级、版本目录切换放入后续阶段实现。

## 后果

正向影响：

- 可显著降低更新失败对设备可用性的影响。
- 能快速满足稳定首次部署与后续更新的核心目标。
- 为后续手动回滚保留目录结构和状态记录基础。

代价：

- 需要额外的磁盘空间保留备份。
- 自动回退逻辑会增加安装器复杂度，需要补充脚本与状态测试。
