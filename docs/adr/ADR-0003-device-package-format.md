# ADR-0003：设备更新包格式

- 状态：accepted
- 日期：2026-06-07

## 背景

设备运行环境以 Debian / Ubuntu / Armbian 为主，现有更新和部署脚本高度依赖 Bash、`tar`、`systemd` 和目录替换式安装。需要选择一种轻量、稳定且便于长期扩展的设备包格式。

## 决策

- 第一阶段设备包格式采用 `tar.gz`。
- 配套生成 `sha256` 摘要文件和 `manifest.json`。
- 包内承载设备安装所需最小内容，而不是直接复用 GitHub 源码 archive。

## 后果

正向影响：

- 与当前 Linux 设备工具链天然兼容。
- 改造成本低，便于快速替换 GitHub archive 方案。
- 可平滑叠加清单、摘要、回退机制。

代价：

- 不是最终极致方案，后续若要做增量更新或多架构产物，可能需要扩展格式或目录规范。
