The CLI is invoked as `hermes-web-ui <command>` where commands include `start [port]`, `client [port]`, `stop`, `restart [--port]`, `status`, `clear-login-locks [--restart]`, `reset-default-login`, `update`/`upgrade`, and `version`. The MCP servers are invoked without arguments and wait for MCP JSON-RPC on stdin/stdout; the active toolset is selected via `HERMES_MCP_TOOLSET=api|devices|use` or the first positional argument. Authentication is configured through `HERMES_WEB_UI_TOKEN`, `AUTH_TOKEN`, or per-profile `.model-run-token` files under `~/.hermes-web-ui/profiles/<profile>/`.
