`npm install` then `npm run dev` launches both the Vite dev client and nodemon-backed Koa server concurrently. Production build runs `npm run build` which generates OpenAPI, type-checks, builds the Vue app, compiles the server, and finalizes artifacts. Desktop packaging uses `npm run build:desktop` (or platform-specific variants). E2E tests run via `npm run test:e2e`, and the harness validation command is `npm run harness:check`.
