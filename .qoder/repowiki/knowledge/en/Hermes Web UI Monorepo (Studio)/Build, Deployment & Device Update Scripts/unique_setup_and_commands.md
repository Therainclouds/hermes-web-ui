Scripts expect to be run from the repository root. Device deployment scripts require root/sudo and target Armbian systems with `apt`, `systemd`, `timedatectl`, and optional `LOCAL_PROXY` for network acceleration. The update runner expects a JSON request at `${HERMES_WEB_UI_HOME}/updates/update-runner-request.json` and writes state to `${HERMES_WEB_UI_HOME}/updates/update-task-state.json`. `generate-openapi.mjs` scans `packages/server/src/routes` and `packages/server/src/controllers` to produce `docs/openapi.json`. `guard-no-inline-data-urls.mjs` must run after `npm run build` against `dist/client/assets/js`.
