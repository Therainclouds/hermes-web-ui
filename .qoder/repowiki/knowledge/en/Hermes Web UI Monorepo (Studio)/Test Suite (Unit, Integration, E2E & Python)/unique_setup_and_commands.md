Client and server tests run through Vitest with `tests/setup.ts` as global setup. E2E tests require a running app instance and use `TEST_ACCESS_KEY` (a pre-signed JWT) plus `authenticate()` to seed `hermes_api_key` in localStorage before navigation. The fake MCP server must be reachable on stdin/stdout for any test importing it. Python USB tests prepend `hermes_data/bots/usb` to `sys.path` so they can import local `config`, `mounter`, and `usb_monitor` modules.
