Three cooperating modules with a clear dependency direction: `usb_monitor.py` is the process entry point (runnable via `__main__`) that owns the pyudev netlink monitor loop, heartbeat thread, cold-scan thread, and JSON event emission; `mounter.py` encapsulates all filesystem probing (`blkid -o export`), mount/umount orchestration via `subprocess`, `/proc/mounts` inspection, and UUID-based mount-point resolution; `config.py` provides a frozen `USBMonitorConfig` dataclass loaded from environment variables plus helper utilities. The monitor imports mounter and config at runtime with try/except ImportError fallbacks so each module can also be executed standalone. External dependencies are strictly confined to `pyudev` (device enumeration) and standard Linux utilities (`mount`, `umount`, `blkid`, `sudo`).
