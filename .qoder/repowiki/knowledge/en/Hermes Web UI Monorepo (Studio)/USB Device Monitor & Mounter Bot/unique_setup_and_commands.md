Run as `python -m hermes_data.bots.usb.usb_monitor` or `python hermes_data/bots/usb/usb_monitor.py`. Requires `pyudev` installed and typically root/sudo privileges for mounting. Configuration is driven entirely by environment variables such as `HERMES_WEB_UI_HOME`, `USB_MOUNT_ROOT`, `USB_LOG_DIR`, `USB_HEARTBEAT_INTERVAL_SECONDS`, `USB_SUPPORTED_FILESYSTEMS`, `USB_MOUNT_OPTIONS`, `USB_ENABLE_COLD_SCAN`, `USB_USE_SUDO`, and command overrides like `USB_MOUNT_COMMAND` / `USB_UMOUNT_COMMAND` / `USB_BLKID_COMMAND` / `USB_SUDO_COMMAND`.
